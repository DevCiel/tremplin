# Tremplin governance

Tremplin is maintained by Devciel. Maintainers set the roadmap, review contributions, manage releases, and protect the framework's accessibility and compatibility contracts.

Technical decisions are documented in pull requests and project documentation. Significant public API changes require maintainer review, migration guidance, and a prerelease period. Security fixes may use an expedited private process.

The project welcomes design, implementation, documentation, testing, accessibility, and localization contributions. Participation must remain respectful and focused on building a dependable open-source framework.
