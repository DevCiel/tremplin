## Verification approach

`tests/helpers/pinned-sass.ts` compiles both production Sass and the separate branded upstream stage under `artifacts/bootstrap6-strict/<commit>/scss`. It checks the stage commit, product version, all 102 Sass module hashes and safe relative paths before using that reference. It never populates the reference with production source or refreshes it to make tests pass. The existing source audit and stage validation independently enforce reference provenance.

Layout-only output and configured generator cases are compared with that reference, alongside explicit assertions for selectors, values, query boundaries, direct children, map overrides and generation flags. Cascade tests preserve complete rule/at-rule topology rather than hiding unlayered rules. Full value parity involving Datepicker's approved SVG exception remains the responsibility of `check:production-css`.

Only Sass's known `color-4-api` compiler deprecation is silenced in this helper. Other warnings and all compilation errors remain visible. Tests are not skipped, the default suite still includes these files, and framework assertion timeouts remain unchanged. CPU-bound full-entry compilation uses a separate one-time setup allowance; the focused command limits Sass workers to two.

## Upstream limitations preserved explicitly

- `make-cssgrid(1)` currently iterates start positions from 1 through 0, emitting `.g-start-0`. The test records this pinned limitation; the framework is not silently patched. Use a coherent multi-column layout pending a separately reviewed upstream update or source exception.
- An unmatched `container-max-widths` key currently yields a null breakpoint prefix and an unqueried `.container` maximum. The test records this rather than pretending the pin filters unknown keys. Keep breakpoint and maximum-width maps coherent; remove unused default maximum keys explicitly with `null`.
- Default `2xl` is a Sass numeric/unit map key, not the quoted string `'2xl'`. Quoted custom keys work when explicitly configured, but are not implicitly coerced to the default numeric key.
