# Tremplin Icons

The icon sprite contains original, dependency-free interface, navigation, status, editing, account, and file-action symbols. Browse the searchable catalog at `/icons/` in the documentation site. Reference a symbol from the distributed sprite and include an accessible label on the containing control when the icon has meaning.

```html
<svg class="icon" aria-hidden="true"><use href="tremplin-icons.svg#search"></use></svg>
```

The v0.8 sprite contains 32 symbols. It covers actions, navigation, status,
accounts, commerce, development, localization, and file operations. The
searchable documentation catalog is generated directly from the sprite, so it
is always the authoritative symbol list.
