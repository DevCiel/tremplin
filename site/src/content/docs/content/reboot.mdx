<section class="docs-section" aria-labelledby="section-0">
<h2 id="section-0">Approach</h2>

<p>Reboot supplies a common starting point for document elements. It is global CSS, not a component you opt into with a class. Review an existing application’s reset before adding it, and avoid loading the focused reboot build alongside the full framework unnecessarily.</p>

</section>

<section class="docs-section" aria-labelledby="section-1">
<h2 id="section-1">Root CSS variables</h2>

<p>Body consumes body-font-family, body-font-size, body-font-weight, body-line-height, fg-body and bg-body. The default sans stack starts with -apple-system/BlinkMacSystemFont and Segoe UI; it deliberately omits system-ui. No web font is downloaded by the framework. The documentation shell can style its own typography independently.</p>

<section class="docs-section" aria-labelledby="section-3">
<h2 id="section-3">Headings and paragraphs</h2>

<p>All h1 through h6 and matching h1–h6 classes use named font-size tokens, configured heading margins and a 1.2 line-height. Paragraphs use paragraph-margin-bottom. Choose heading levels semantically.</p>

<section class="docs-section" aria-labelledby="section-4">
<h2 id="section-4">Links and horizontal rules</h2>

<p>Links use a runtime color and underline offset. A horizontal rule draws a themed block-start border. Keep link purpose clear without relying on color alone.</p>

<p>This live link explicitly uses primary-fg-emphasis as application CSS for normal-text contrast; it does not alter the pinned link default.</p>

<section class="docs-section" aria-labelledby="section-5">
<h2 id="section-5">Code, user input, and sample output</h2>

<p>code, pre, kbd, and samp use the monospace stack. Preformatted blocks scroll when necessary. Escape user-provided source text before putting it into HTML; CSS does not make unsafe markup safe.</p>

<section class="docs-section" aria-labelledby="section-6">
<h2 id="section-6">Forms and miscellaneous elements</h2>

<p>The local reset only normalizes part of native form and document styling. Use the dedicated <a href="/forms/overview/">{"Forms guide"}</a> for controls, visible labels, validation, and keyboard behavior. Details/summary, address, embeds, and other native elements must still be tested across supported browsers.</p>

</section>

<section class="docs-section" aria-labelledby="section-7">
<h2 id="section-7">Hidden content and reduced motion</h2>

<p>Reboot enforces hidden with display:none !important. Smooth scrolling is opt-in and only enabled when reduced motion is not requested. Transition mixins and individual components handle their own preference rules; Reboot does not globally shorten every application animation.</p>

<p>Iframes receive color-scheme: light dark; third-party embed contents still require independent review.</p>
