<h2 id="section-1">How it works</h2>

<p>colors emits runtime palette properties; theme defines semantic roles and light-dark() values; root emits role references and other global tokens. Semantic names are primary, accent, secondary, success, danger, warning, info and inverse. A base color is not a universal accessible foreground/background pair.</p>
