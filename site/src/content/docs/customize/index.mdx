## Configure once

Configure the main Sass module once, before it is loaded elsewhere:

<Code sample={customizeExamples['customize/sass#2'].code[0]} standalone={true} />

The full entry exposes configuration and theme maps, plus component-owned token maps. Use `sass:map` with `config.$spacers` for spacing values, and import mixins explicitly from their owning modules, such as `mixins/focus-ring`, `mixins/visually-hidden`, or `layout/breakpoints`. The main entry does not re-export every Sass helper. See the [Sass guide](/customize/sass/) for load order and forwarding details. Runtime themes override `--trm-*` properties without renaming public classes.

For focused bundles, import `tremplin-grid`, `tremplin-reboot`, or `tremplin-utilities` from the published Sass source.
