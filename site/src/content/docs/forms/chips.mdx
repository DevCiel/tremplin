<section class="docs-section" aria-labelledby="section-3">
<h2 id="section-3">{"Keyboard and cancellation"}</h2>

<p>{"clear() removes all chips directly and emits change, bypassing per-chip remove cancellation. removeSelected() uses remove() and respects each veto."}</p>

<p>{"Duplicate matching is case-sensitive. Initial seeded chips are initialized rather than revalidated against duplicates/maxChips; rejected Enter/blur attempts can discard the attempted text."}</p>

<p>{"Generated dismiss buttons use aria-label=Remove and tabindex=-1; authored controls keep their own labels and tab order. The chip itself handles keyboard removal."}</p>

<p>{"Native disabled input styling does not freeze existing-chip keyboard handlers or programmatic add/remove. dismissible=false is not read-only mode."}</p>

<p>{"RTL changes layout but not physical ArrowLeft/Right DOM-index navigation. Do not advertise a roving ARIA listbox or automatic selection announcements."}</p>

</section>
