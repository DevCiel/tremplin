<h2 id="section-1">{"Disabled forms"}</h2>

<p>{"Use disabled on an individual native control or fieldset. Native controls in a disabled fieldset cannot normally be edited, focused or submitted; descendants of its first legend are the native exception. That does not disable links or custom widgets. For non-native actions, prefer a disabled native button or remove navigation/activation and expose aria-disabled=\"true\" deliberately; ARIA alone does not block behavior."}</p>

<section class="docs-section" aria-labelledby="section-3">
<h2 id="section-3">{"Accessibility"}</h2>

<p>{"Visible labels are the default. Use for/id, fieldset/legend for questions, aria-describedby for help and errors, and required in both markup and understandable text. A placeholder is not a durable label. A visually-hidden label is an alternative only when the visual context still makes the purpose clear."}</p>

<p>{"Native controls own keyboard behavior; CSS does not implement submission, persistence, error announcements or summary focus. Prefer persistent feedback and a recovery path. See "}<a href="/getting-started/accessibility/">{"Accessibility"}</a>{" and "}<a href="/forms/validation/">{"Validation"}</a>{"."}</p>
