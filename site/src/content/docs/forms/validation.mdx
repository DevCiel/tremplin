<h2 id="section-0">{"How it works"}</h2>

<p>{"data-trm-validate opts a subtree into native :user-invalid feedback after interaction. Its valid token additionally opts into :user-valid; scope success feedback to useful constrained fields. Explicit is-invalid/is-valid classes work globally. None of these creates messages, sets ARIA or checks server rules."}</p>

<p>{"novalidate suppresses browser submit-time UI, not the validity API or server requirements. Native user-* timing varies by browser; explicit classes make the custom demo deterministic. The retired was-validated contract is not strict core."}</p>

</section>
