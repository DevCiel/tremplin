<section class="docs-section" aria-labelledby="section-3">
<h2 id="section-3">4. Separate build requirements</h2>

<p>A static page using compiled assets does not require Node.js in the browser. Package metadata declares Node.js 20 or newer for the toolchain; check the engine requirements of Vite, Astro, and other tools you choose as well.</p>

</section>

<section class="docs-section" aria-labelledby="section-4">
<h2 id="section-4">5. Handle older environments</h2>

<p>Do not claim compatibility based only on JavaScript transpilation. CSS features and native dialog behavior also matter. Define your application baseline, feature-test critical paths, and supply an application-specific fallback or an understandable unsupported-browser message.</p>

</section>
