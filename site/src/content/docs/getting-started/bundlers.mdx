<section class="docs-section" aria-labelledby="section-6">
<h2 id="section-6">7. Webpack and other bundlers</h2>

<p>Use the same declared package imports. Configure your existing tool’s CSS and Sass processing and install the Floating UI peer. Browser-native ESM cannot resolve bare package specifiers without additional resolution; plain HTML can use the self-contained ESM bundle with type={'"module"'}, or a standard build with the Install guide’s import map. This guide provides a complete Vite recipe, not a tested configuration for every bundler.</p>

</section>

<ol class="docs-steps">
