<section class="docs-section" aria-labelledby="section-3">
<h2 id="section-3">4. Keep declarations and maps straight</h2>

<p>TypeScript declarations describe the API and are resolved through package exports; they are not browser scripts. Source maps support debugging and can be deployed or withheld according to your application policy. Source TypeScript and Sass are inputs, not compiled browser assets.</p>
