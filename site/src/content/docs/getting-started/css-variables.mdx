<section class="docs-section" aria-labelledby="section-4">
<h2 id="section-4">5. Know the boundary</h2>

<p>CSS variables cannot be substituted directly into media-query conditions. Change generated breakpoint values and spacing maps through Sass instead. Some components define their own local variables, so consult that component’s variables table when a root override has no effect.</p>
