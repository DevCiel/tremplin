<section class="docs-section" aria-labelledby="section-4">
<h2 id="section-4">5. Test directional interactions</h2>

<ol class="docs-steps">
<li>Verify drawer placement, menu positioning, horizontal navigation, and Datepicker arrow keys.</li>
<li>Check nested mixed-direction regions, focus order, and reading order.</li>
<li>If an application changes language at runtime, retest or recreate affected plugin instances so cached positioning and direction state are refreshed.</li>
</ol>

<div class="docs-callout docs-callout-info">The same stylesheet supports both directions. RTL styling does not translate your text, labels, date locale, or icon meaning; those remain application responsibilities.</div>
