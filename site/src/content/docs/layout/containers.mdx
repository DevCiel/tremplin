<section class="docs-section" aria-labelledby="section-0">
<h2 id="section-0">How they work</h2>

<p>A container supplies full available width, automatic inline margins, and half a horizontal gutter on each side. The default container gains a maximum width at each configured viewport threshold. Nest rows within a container so their negative margins balance its padding.</p>

<h2 id="section-4">CSS and Sass</h2>

<p>{"Container padding is half --trm-gutter-x on each side; container-padding-x defaults to grid-gutter-x. Width/max-width are physical, margins/padding logical. Breakpoint and maximum maps must have coherent keys; unmatched keys are not silently ignored."}</p>

<p>Grid-only CSS does not include Reboot. Supply border-box sizing separately. Root palette/color tokens are not part of the focused Grid output.</p>
