<section class="docs-section" aria-labelledby="section-1">
<h2 id="section-1">How it works</h2>

<p>A row is a wrapping flex container. Its direct children get column padding and default to full width. Assign col for equal-width columns or col-N for a fraction of the configured column count. Keep nested rows inside a column, not directly beside column content without an enclosing structure.</p>

</section>

<section class="docs-section" aria-labelledby="section-5">
<h2 id="section-5">Grid-only distribution</h2>

<p>The focused bundle includes display, order, Grid tracks/flow, gap, Flexbox/alignment and spacing families. It excludes Reboot, components, general color/sizing utilities and full palette/root output. Supply application-wide base styles separately.</p>

<p>Mapped families support shallow complete replacement, null removal and per-family importance/variant flags. No separate compatibility ordering generator remains. Print/dark variants require explicit opt-in.</p>

<p>Grid-only CSS deliberately excludes Reboot: pair it with a reset or supply border-box sizing. Breakpoint properties on :root/:host are inspection tokens; overriding them does not change compiled queries.</p>
