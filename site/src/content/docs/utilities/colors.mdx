<h2 id="section-3">{"Opacity and inheritance"}</h2>

<p><Html source={"fg-* assigns the non-inheriting --trm-fg composition token. fg-50 mixes that local role with transparent; there is no currentcolor fallback, so pair it with a role. Ordinary CSS color still inherits. fg-reset explicitly inherits the composition token; it is not a hard-coded body color. Lower alpha and weaker role levels can fail text contrast."} /></p>
