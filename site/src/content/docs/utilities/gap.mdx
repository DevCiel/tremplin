<h2 id="section-4">{"Responsive gaps"}</h2>

<p><Html source={"md:row-gap-4 applies at the default md minimum viewport width of 768px. Only prefix-style responsive names are generated. Each gap family is responsive by default; print, dark, and state variants require a family override. With equal importance and specificity, the generated cascade order decides the result, not class order in the HTML. Base axis controls follow base gap shorthands, but a wider responsive shorthand can replace both axes; override that axis at the same breakpoint when needed."} /></p>
