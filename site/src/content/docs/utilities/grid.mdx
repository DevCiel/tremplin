<section class="docs-section" aria-labelledby="section-3">
<h2 id="section-3">{"Track counts and full-width items"}</h2>

<p><Html source={"grid-cols-1, grid-cols-2, grid-cols-3, grid-cols-4, and grid-cols-6 create equal 1fr tracks, matching the upstream values. There is no default grid-cols-5. Unlike minmax(0, 1fr), a plain 1fr track retains its automatic minimum: long intrinsic content can overflow a narrow box. Use min-w-0, wrapping, and suitable content sizing where needed."} /></p>

<p><Html source={"grid-cols-fill belongs on a grid item and sets grid-column: 1 / -1 across all explicit columns. It is not a column count. Use md:grid-cols-3 for the canonical responsive prefix. Grid utilities use shared viewport breakpoints, not container-query variants; infix aliases are not generated."} /></p>

</section>

<section class="docs-section" aria-labelledby="section-4">
<h2 id="section-4">{"Subgrid"}</h2>

<p><Html source={"Place d-grid grid-cols-subgrid on a grid item that spans multiple parent columns to reuse their track lines and column spacing. Add grid-cols-fill to span the entire explicit parent grid. Subgrid is only useful inside a parent Grid; it does not create a standalone set of equal tracks. Check your supported browser versions before depending on it."} /></p>

<section class="docs-section" aria-labelledby="section-5">
<h2 id="section-5">{"Auto-placement and reading order"}</h2>

<p><Html source={"grid-auto-flow-row places items by row; grid-auto-flow-column places them by column. Set rows and implicit column sizing as appropriate for column flow. grid-auto-flow-dense enables dense row packing, which can visually move later items into earlier holes. CSS placement does not reorder the DOM, reading order, or keyboard tab order. Avoid dense placement for ordered, interactive content when the visual order would become misleading."} /></p>

</section>

<section class="docs-section" aria-labelledby="section-6">
<h2 id="section-6">{"Utilities versus layout helpers"}</h2>

<p><Html source={"Use d-grid for this utility-first API. The grid layout container defaults to twelve 1fr tracks, a 1.5rem gap and inline-size containment. Ordinary children auto-place normally; g-col/g-start set literal placement. Keep track counts and item spans coherent to avoid implicit tracks. See the CSS Grid guide for container-responsive placement."} /></p>

<p><Html source={"The new utility families remain available when $enable-cssgrid is false; that switch controls only the layout helper module. Utility removal and configuration use the grid-column-counts, grid-columns, and grid-auto-flow map keys. Declarations are not important by default. Set important: true on an individual mapped family when needed; there is no global importance flag."} /></p>

</section>
