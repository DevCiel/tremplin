## Working locally

See the complete [Utility API](/utilities/api/), [breakpoint reference](/layout/breakpoints/), [container reference](/layout/containers/), and [grid guide](/layout/grid/).

The twelve-column flex grid, CSS Grid alternative, and container-query helpers share the same responsive vocabulary.

```html
<div class="container">
  <div class="row row-cols-1 md:row-cols-2 lg:row-cols-4 g-3">
    <article class="col">...</article>
  </div>
</div>
```

Utilities support selected spacing, sizing, display, flex, typography, color, border, overflow, opacity, state, dark, and print behavior. Not every family supports every variant.

```html
<section class="d-flex flex-column lg:flex-row lg:align-items-center gap-3 p-3 lg:p-5">
  <button class="btn-solid theme-inverse">Launch</button>
</section>
```

Override `$utilities`, `$spacers`, `$breakpoints`, or a specific family map through Sass module configuration to generate a custom build.
